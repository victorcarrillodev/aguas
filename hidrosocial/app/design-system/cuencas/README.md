# Cuencas (nivel plantilla/página)

Las cuencas son las páginas completas: componen cauces, corrientes y gotas
contra los datos de un loader. **Viven en `app/rutas/`** (`RutaDashboard`,
`RutaCaptura`, `RutaGrafo`, `RutaGrafoNodo`, `RutaNodo`); este directorio
solo documenta el nivel, no contiene componentes.
