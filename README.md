# aguas

**Diagnóstico del sistema hidrosanitario del Área Metropolitana de Guadalajara**
Consejo Social y Científico por el Agua

---

Este repositorio contiene el diagnóstico construido como **árboles de problemas**: un problema central, sus causas, y las causas de sus causas. No es una lista de quejas ni un catálogo de propuestas — es el mapa de por qué el sistema funciona como funciona, ordenado para poder planear encima de él.

## La tesis, en cinco frases

1. Los habitantes del AMG, la cuenca y el erario padecen un servicio-derecho al agua **deficiente, inequitativo e insostenible**.
2. Eso lo producen **diez causas estructurales**, cada una real y atacable por separado.
3. Esas diez no son independientes: **se tocan por debajo** y se sostienen entre sí.
4. Debajo de todas hay un **arreglo institucional sin árbitro**.
5. Y una **raíz maestra**: sin medición verificable y sin fiscalización real, **ninguna corrección se sostiene**.

## Por dónde empezar

Abre **[`Inicio.md`](Inicio.md)**. De ahí sale todo.

## Cómo está organizado

| Carpeta | Qué contiene |
|---|---|
| `1 · El problema` | El tronco: el problema central, el eje regresivo, el basamento y la raíz maestra |
| `2 · Las causas` | Diez capítulos, uno por causa estructural. Se leen de corrido |
| `3 · Las fichas` | El detalle de cada una de las 57 condiciones que desglosan esas causas |
| `4 · Los actores` | Quién ofrece, quién demanda, quién arbitra — y quién causa contra quién debería resolver |
| `5 · Los efectos` | La copa: lo que el sistema produce hacia arriba |
| `6 · Las mediciones` | Los treinta indicadores con que se dimensionaría cada cosa |
| `7 · El método` | Cómo se lee un árbol, las cuatro reglas, las cinco capas |
| `8 · Mapas` | El modelo dibujado, en lienzos navegables |

## Cómo leerlo

Se lee como texto plano: no hace falta instalar nada. En GitHub se navega directo desde `Inicio.md`.

Si lo abres como bóveda de [Obsidian](https://obsidian.md) —clonando el repositorio y abriendo la carpeta— además funcionan los enlaces entre notas, la vista de grafo y los mapas de la carpeta `8 · Mapas`. Tampoco requiere plugins.

## Estado

Todo el diagnóstico está **en revisión**. Ninguna afirmación ha recibido validación formal del Consejo: es material de trabajo abierto a discusión y corrección.

Los treinta indicadores no tienen línea base pública. Eso no es un pendiente de captura, es un hallazgo: sobre un sistema que no se mide, el dato no existe. La ausencia del dato *es* el dato, y es la mitad del argumento de la raíz maestra.
